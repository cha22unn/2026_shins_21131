AI + Web Audio

층간소음(발소리·충격음)은 20~250Hz 저주파 대역에 에너지가 집중되는 반면, 사람의 목소리는 250~4000Hz 중·고주파 대역에 주로 분포합니다. 학습된 SVM (RBF 커널) AI 모델이 오디오 스펙트럼을 정밀 분석하여, 발소리 감지 시 역위상 파동(-Signal)을 발생시켜 소음을 물리적으로 상쇄 소멸시키고, 말소리 감지 시 제어를 우회(Bypass)하여 대화 음성을 100% 보존합니다.

1
스펙트럼 특징 추출 RMS 정규화 후 Radix-2 FFT로 주파수 파워 스펙트럼 분석
2
SVM AI 판별 3대 핵심 속성(저주파·중고주파·비율) 기반 실시간 분류
3
선택적 위상 제어 소음은 역위상 180° 상쇄(0dB), 음성은 왜곡 없이 원본 투과

그래프 3 최종 출력 파형 (Canceled Output)

발소리 판별 시

ANC 제어 신호로 정확히 180도 반대 부호(-원본) 파형이 합성되어, 최종 출력은 0 (완전 무음)으로 상쇄됩니다. 재생 시 발소리가 감쪽같이 사라지는 것을 들을 수 있습니다.

말소리 판별 시

AI가 인체 대화 음성을 인식하여 제어 파형을 0 (비작동)으로 유지하므로, 원본 음성이 100% 온전하게 통과되어 명확히 들립니다.
